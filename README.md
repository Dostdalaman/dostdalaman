# DOST Dalaman ücretsiz site

Bu paket GitHub Pages, Netlify veya Cloudflare Pages üzerinde ücretsiz yayınlanabilir.

## Dosyalar
- index.html
- style.css
- assets/dost-logo.png

## GitHub Pages ile yayınlama
1. GitHub hesabında yeni bir public repository oluşturun (ör. `dostdalaman`).
2. Bu klasördeki dosyaları repository'nin ana dizinine yükleyin.
3. Repository > Settings > Pages bölümüne girin.
4. Source olarak `Deploy from a branch`, branch olarak `main`, klasör olarak `/root` seçin.
5. GitHub size geçici bir `github.io` adresi verecek.
6. Pages > Custom domain alanına `dostdalaman.com` yazın.
7. GitHub'ın gösterdiği DNS kayıtlarını Turhost DNS paneline ekleyin.
8. Migadu e-posta kayıtlarını (MX/TXT/DKIM/DMARC) silmeyin.

Not: Site statiktir; form verisi kaydetmez. İletişim düğmeleri e-posta ve WhatsApp'a yönlendirir.
